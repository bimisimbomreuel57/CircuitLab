# CircuitLab

A Python-based electrical and electronic circuit simulator.

## Overview

CircuitLab is a circuit simulation project designed to allow users to build, configure, and simulate electrical and electronic circuits digitally. It aims to provide accurate circuit analysis, fault detection, and structured error reporting.

## Project Status

Currently in the planning and architectural design phase.

## Technology Stack

- **Python** — Core simulation engine
- **NumPy & SciPy** — Numerical and scientific computation
- **FastAPI** — Backend API
- **React & TypeScript** — Frontend

## Development Roadmap

1. Component System
2. Circuit Modelling
3. Simulation Engine
4. Diagnostics System
5. Backend Development
6. Frontend Development
7. Integration and Testing

## Vision

To develop a reliable, modular, and extensible circuit simulation platform, initially targeting the web, with future mobile and desktop support.
